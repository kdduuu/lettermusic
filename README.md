
# Projeto Musical

Plataforma social de música para registrar escutas, avaliar obras, escrever reviews, organizar listas e expressar a identidade musical.

**Status:** início do desenvolvimento.

## Objetivo

Projeto pessoal de portfólio com foco em aprendizado de back-end, arquitetura, bancos de dados e práticas modernas de desenvolvimento.

Não é uma plataforma de streaming.

## Tecnologias

- Python + FastAPI
- PostgreSQL
- SQLAlchemy + Alembic

Frontend e integrações serão incorporados durante o desenvolvimento.

## Desenvolvimento

O projeto será construído em pequenas etapas, priorizando código compreensível, testes e manutenção.
